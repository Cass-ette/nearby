# 附近 / Nearby

> 附近有点东西。  
> 别只路过，把今天留下来。

「附近」是一款关注日常生活与个人感受的 iOS 记录应用。它鼓励用户用照片、文字、心情和地点，留下身边细小但真实的生活瞬间，慢慢形成一条属于自己的时间流和一张个人记忆地图。

不同于传统社交媒体，「附近」不显示点赞数量，不设置关注关系，也不提供评论功能。我们希望减少比较、围观和即时评价带来的表达压力，让记录重新回到个人感受本身。

## 产品定位

在快节奏生活里，人们每天经过很多熟悉的地点，却很少真正停下来感受“附近”正在发生什么。

「附近」希望回应这种日常感知的缺失：它不是一个热闹的信息广场，也不是查看附近陌生人的工具，而是一个更温柔、更克制、更尊重隐私的生活记录空间。

用户可以：

- 随手记录一张照片、一段文字、一个心情；
- 选择记录公开或仅自己可见；
- 即使公开，也可以选择不展示位置；
- 在时间流里回看生活片段；
- 在地图上看见自己走过、停留过、记录过的地方；
- 通过共创话题参与明天的灵感选择。

## 核心特色

### 克制社交

「附近」刻意弱化传统社交平台里的压力机制：

- 不显示点赞数量；
- 不设置关注 / 粉丝关系；
- 不提供评论区；
- 点赞只作为轻量共鸣存在，不作为公开热度排名。

我们希望用户发布一条记录时，首先想到的不是“别人会怎么看”，而是“这一刻是否值得被我留下”。

### 个人记忆地图

地图页面只专注展示用户自己记录过的地点。

它不是导航工具，也不是附近陌生人入口，而是一张个人生活轨迹图。随着记录增加，用户可以看到自己生活中被点亮的角落：街边树影、路口晚霞、校园小路、书店窗台，都会因为一次记录而拥有意义。

### 低压力记录

发布记录时，正文是可选的。用户可以只用标题和照片留下当下，也可以补充更多文字。

记录可以公开，也可以私密；公开时还可以选择是否展示街区位置。产品不强迫用户暴露具体空间信息，而是把表达边界交还给用户。

### 共创灵感

首页提供话题投票与创建话题入口。

用户每天有三票，可以参与选择明天的灵感主题。自己创建的话题设定为平台审核后进入投票池。当前原型阶段主要呈现用户可感知的前端流程，用于比赛展示和产品概念说明。

### 我的记录

个人页弱化头像、关注数、粉丝数等社交身份元素，突出记录本身：

- 记录天数；
- 自己留下的照片墙；
- 喜欢过的记录；
- 徽章与长期沉淀。

它更像一份可以慢慢回看的生活档案，而不是一个等待被评价的主页。

## 功能概览

| 模块 | 说明 |
|---|---|
| 首页 | 静态主入口、开始记录、今日灵感、共创话题、记录概览 |
| 发布 | 最多 12 张照片、标题、可选正文、心情、滤镜、公开 / 私密、位置开关 |
| 时间流 | 浏览公开记录和自己的记录，支持照片组堆叠展示 |
| 地图 | 只展示自己的记录地点，缩小时使用点位，聚焦个人轨迹 |
| 我的 | 记录天数、照片墙、喜欢过的记录、徽章、基础删除功能 |
| 引导页 | 解释产品理念、记录方式和隐私边界 |

## 技术栈

| 层 | 选型 |
|---|---|
| UI | SwiftUI |
| 状态 | `@Observable` + `@Environment` |
| 持久化 | SwiftData |
| 图片 | PhotosUI + Core Image + 异步解码缓存 |
| 位置 | CoreLocation + 模糊街区位置 |
| 地图 | MapKit |
| 本地化 | String Catalog |
| 项目 | Xcode / XcodeGen (`project.yml`) |
| 测试 | XCTest / Swift Testing |

```text

│  ├─ Feed/              时间流、照片组、详情、点赞
│  ├─ Map/               个人地图、点位与记录预览
```

## 运行方式

### 使用 Xcode

1. 打开 `附近.xcodeproj`；
2. 选择 `附近` scheme；
3. 选择模拟器或已连接的 iPhone；
4. 点击 Run。

### 命令行构建

```bash
xcodebuild build \
  -project '附近.xcodeproj' \
  -scheme '附近' \
  -destination 'generic/platform=iOS Simulator'
```

如果需要重新生成 Xcode 工程：

```bash
brew install xcodegen
xcodegen generate
```

## 设计方向

| 维度 | 方向 |
|---|---|
| 色彩 | 暖白背景、陶红强调色、低饱和辅助色、轻玻璃质感 |
| 字体 | 大标题强化情绪，正文保持清晰克制 |
| 布局 | 大卡片、大留白、单一主入口，减少信息压迫 |
| 组件 | 圆角卡片、柔和阴影、半透明材质、轻边框 |
| 交互 | 低负担发布、隐私选择明确、减少即时反馈压力 |

## 人文关怀

「附近」关注的是数字产品中的“人”。

在许多社交平台强调曝光、互动和数据反馈的当下，我们希望保留一个更安静、更安全的表达空间。生活不必被围观才有价值，表达不必被评价才有意义。

通过个人记忆地图、低压力记录和克制社交机制，「附近」希望帮助用户重新看见自己的生活，也重新看见身边那些普通、细小、容易被忽略的瞬间。
